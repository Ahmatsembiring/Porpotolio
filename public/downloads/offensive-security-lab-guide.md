# Offensive Security Lab Guide

Panduan ini menjelaskan cara menyusun lab latihan keamanan aplikasi web secara aman dan terkontrol.
Materi ini tidak ditujukan untuk menyerang sistem pihak lain.

## Prinsip Lab Aman

- Jalankan hanya di environment lokal atau sandbox.
- Gunakan data dummy, bukan data pribadi.
- Pisahkan lab dari jaringan production.
- Dokumentasikan setiap skenario dan mitigasi.
- Tambahkan logging agar proses deteksi terlihat.

## Skenario Latihan

- Login form dengan validasi input.
- Search form untuk memahami risiko injection.
- Comment form untuk memahami output encoding.
- Upload form untuk memahami validasi file.
- Role user/admin untuk memahami access control.
- Security dashboard untuk membaca log.

## Output Portfolio

- Screenshot dashboard.
- Ringkasan skenario.
- Temuan dan bukti aman.
- Mitigasi teknis.
- Pelajaran yang didapat.
