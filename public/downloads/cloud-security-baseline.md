# Cloud Security Baseline Checklist

Checklist baseline untuk membantu review keamanan cloud.

## Identity and Access Management

- Aktifkan MFA untuk akun penting.
- Hindari penggunaan root account harian.
- Terapkan least privilege.
- Review access key secara berkala.

## Network and Exposure

- Batasi security group yang terbuka ke internet.
- Gunakan private subnet untuk service internal.
- Review public IP dan open port.

## Data Protection

- Aktifkan encryption at rest.
- Aktifkan encryption in transit.
- Review policy bucket atau object storage.
- Aktifkan backup dan retention policy.

## Monitoring

- Aktifkan audit trail.
- Kirim log ke lokasi terpusat.
- Buat alert untuk aktivitas tidak biasa.
